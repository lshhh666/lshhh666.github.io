# 作品与文章页调整

在 `codex/修改ui界面` 分支完成。首页灯塔光影与鼠标靠近增亮保持原样。

## 作品素材

本地字幕的真实截图来自该项目已有文件 `D:/translate/work/packaged-launcher-final.png`，原样复制到 `public/images/projects/local-live-captions.png`，尺寸为 856 × 779。画面是 Windows 控制台及其内置字幕预览，不是正在捕获音频的录屏。

作品说明以 `D:/translate/README.md` 和博客既有项目字段为依据：v0.1 测试版、Windows 11 / RTX 4060 8 GB 录屏验证、其他设备和语言场景仍待验证。未添加用户量、性能成绩或未经确认的项目成果。

新增项目字段均为可选：`coverAlt`、`coverCaption`、`coverWidth`、`coverHeight`、`problem`、`contribution`、`progress`。作品页读取排序首项作为重点项目；无截图时保留文字布局，无详情字段时省略对应说明。截图尺寸用于预留布局空间。首页和作品页共享内容集合中的真实截图。

## 阅读细节

- 标题保留完整文本，将英文词组作为可整体换行的片段；过长片段仍允许折行。
- 使用文章已有摘要，提亮日期、标签与阅读信息；分类入口移至标题上方，避免重复。
- 版权说明保持作者、日期、许可与正式站点原文链接，移除重复标题、大水印及本地预览地址。
- 相邻文章标题完整展示，只有一个相邻条目时占满宽度，并提供归档入口。
- 手机内页边距统一为 24px。

## 验证

Astro 检查、生产构建与 Pagefind 索引通过。浏览器覆盖 320、390、768、1440、1920px；检查作品截图、两篇文章、导航、正式原文链接、标题换行和横向溢出。模拟截图延迟加载，验证图片加载前后占位高度一致。首页灯塔组件与星点组件未修改。

## 归档、关于与全站细节

- 归档改为开放式年份时间线，分类和标签筛选放在列表上方。同组多选取并集，分类与标签之间取交集；筛选保留在 URL 中，支持清空、浏览器前进/后退及未知条件的空状态。静态 HTML 包含全部文章，无 JavaScript 时仍可阅读和跳转。
- 关于页使用现有个人介绍、GitHub 联系方式与项目集合，近期项目按“正在维护”“原型阶段”状态展示，没有增加个人经历。
- 桌面和手机导航标明当前位置；页脚统一留白、字色和换行。增加“跳到正文”和键盘焦点样式。
- 搜索关闭时设为 inert，Esc 返回入口，手机打开后聚焦输入框；取消过期请求，清空关键词时结束加载状态，重开时重新查询保留的关键词。

本轮验证覆盖 320、390、768、1440、1920px 的首页、归档、关于、作品和文章页；验证组合筛选、历史前进/后退、无 JavaScript 的文章入口、生产搜索、键盘跳转、手机菜单和搜索开合。搜索额外模拟延迟响应，验证关闭、清空和重新打开的行为。
