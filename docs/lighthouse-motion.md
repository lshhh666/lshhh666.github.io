# 灯塔首页与光影动效

本地分支：`codex/修改ui界面`。基于已确认的首页概念稿，使用项目原有灯塔照片和文章、作品数据。

## 光影实现

`src/components/LighthouseHero.astro` 将原图、SVG 光层放进同一个保持 `2400 × 1601` 比例的画布。灯头锚点为 `(1545, 806)`。ResizeObserver 根据容器高度计算 cover 尺寸，手机和桌面共用这一坐标系，因此裁切、微弱鼠标视差不会让光束离开灯头。

- **光束**：带径向渐变和柔边的 SVG 扇形，以灯头为轴在 `-8°` 和 `8°` 之间缓慢往返，18 秒一轮；同时改变透明度。
- **灯头**：独立柔光晕，9 秒呼吸周期。
- **薄雾**：两组低透明度椭圆渐变分别以 28 秒、22 秒周期缓慢横移，产生远近层次。
- **反光**：裁切到水面区域的柔光及细横纹。整体亮度与光束同为 18 秒周期，横纹采用错开的 5 秒周期，轻微移动并明暗变化。

这是照片上的分层光影合成。原图里已存在的宽幅光束和海面不会真实旋转、流动；新增光束在原光晕范围内偏转，薄雾和反光负责局部变化。若以后需要大角度灯塔旋转或真实海浪，应换用分离光束的底图或视频素材。

## 控制和性能

- 首屏右下角提供暂停／播放按钮，`aria-pressed=true` 表示用户已暂停。
- 首屏离开视口、页面切至后台时自动暂停；返回时只恢复未被用户暂停的动画。
- 响应系统 `prefers-reduced-motion` 的初始值及运行时变化，关闭动画和视差。
- CSS 动画驱动光影，无持续 JS 动画循环；鼠标视差只在精细指针输入时按需请求一帧。
- 无 JavaScript 时保留静态首屏、文章和链接，隐藏动效按钮。
- 原全站交互星场替换为 22 个静态细光点，透明度降低并遮罩在页面边缘。手机内页不显示星点。

## 页面内容

首页文章读取实际摘要并保留分页；主推作品读取作品集合的排序首项。主推字幕项目缺少实际截图时，明确展示“布局示意 · 非产品截图”；配置 `cover` 后会使用真实图片。导航保留搜索、归档、作品及关于入口，移动菜单补充 inert、Escape 和展开状态。
